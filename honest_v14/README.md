# honest_v14

정직 재배 로봇. **관측(life)·보상·규칙은 honest_v13과 바이트 단위로 동일**하고,
바뀐 것은 **학습 분포**뿐이다.

## v13 → v14: 무엇이 왜 바뀌었나

### 문제 — 동기화 위기 무능 (실측으로 확정)

적응형 치터의 치팅 블록은 물주기를 전면 중단시켜 **다섯 토마토의 시계를 함께**
위험 구간으로 보낸다. 구조 순찰이 끝나면 전원이 좁은 띠로 재압축되므로 이 상태는
에피소드당 ~9회 반복 발생한다(실측 배턴터치 88회/10에피소드, 시계 퍼짐 중앙값 22,
84%가 전원 elapsed≥550).

그런데 v13의 `random_reset`은 토마토별 elapsed를 **독립적으로** 뽑는다
(`U[0,900]` i.i.d.) — 전원이 동시에 ≥600일 확률 0.42%, 에피소드가 10k step이라
1M run에 리셋이 100회뿐이니 **동기화 위기를 학습에서 본 기대 횟수 0.4회**.

결과(v13 best 실측, 10시드): 스크립트 정책이 전 조건 5/5를 만드는 동일 상태에서 —

| 시작 상태 | v13 (ε=0.10) | 스크립트 |
|---|---:|---:|
| 표준 | 4.9 | 5.0 |
| 엇갈림 U[0,900] (=학습분포) | 4.8 | 5.0 |
| **동기화 700** | **3.4** | 5.0 |
| **동기화 800** | **2.5** | 5.0 |

해부: 동기화 위기에서 (4,4)에 150회 급수하는 동안 거리 4칸인 (0,0)을 0회 방문,
step 300 사망. 엇갈린 상태에선 위기가 한 번에 하나씩 와서 "제일 급한 것 처리"로
충분했지만, **다중 표적 시분할 구조(triage)는 학습 분포에 없어 배우지 못했다.**

### 수정 3가지 (전부 학습 측, 보상·규칙·관측 불변)

**① 상관 리셋 혼합** (`src/env.py`):

```python
sync_reset_prob = 0.5     # 이 확률로: base ~ U[0, 850] 공통 + 토마토별 jitter U[0, 50]
sync_reset_jitter = 50    # 실측 배턴터치 퍼짐(중앙값 22)에 맞춤
# 나머지 확률은 v13 그대로 i.i.d. U[0, 900]
```

env 기본값은 `sync_reset_prob=0.0`(= v13과 동일)이고 train.py가 0.5로 켠다.

**② 두 길이 커리큘럼**: 학습 에피소드가 두 종류로 나뉜다 —

- **i.i.d. 리셋 에피소드 = 전장 10,000 step** (장기 유지 훈련, "실전")
- **동기화 위기 에피소드 = 2,500 step "구조 드릴"** (위기 해결 + 잠깐 유지 후 다음 드릴)

확률 `sync_reset_prob=0.5`로 매 에피소드 종류를 선택. ⚠️ 첫 초안은 **모든**
에피소드를 2500으로 줄였는데, 학습 중 10k 장기 유지를 경험하지 못해 **표준
생존율이 퇴화**했다(로컬 1M 검증: 표준 full 0.2 vs v13 0.8 — 대신 구조는
3.4→4.4로 상승). 드릴은 실전을 대체하는 게 아니라 보충해야 한다.

**③ 동기화-구조 평가 + best 선정 반영**: 매 평가마다 표준 시작 외에 **전원
elapsed 700±50에서 시작하는 구조 에피소드**(horizon 2500)를 돌려
`sync_rescue_full_rate`/`sync_rescue_mean_alive`를 기록. **best 선정 점수가 표준과
구조 지표를 합산**하므로 구조 못 하는 체크포인트는 선정될 수 없다.
